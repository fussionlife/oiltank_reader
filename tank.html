노즐별 출고량 → 탱크별 일평균 자동 계산

노즐회전량관리 엑셀 파일을 선택하면 노즐별 출고량과 기간이 자동 입력됩니다. 붙여넣기·직접 입력도 가능합니다. 노즐→탱크 연결은 한 번만 지정하면 계속 저장·유지됩니다. 계산식: 탱크 일평균(드럼) = 노즐 출고합계(L) ÷ 200 ÷ 기간 일수.
시간대별 판매 비교 — 전일 vs 금일 (현재 시각까지) 판매내역조회(상세) 파일 기준 · 날짜=판매일자 · 시간=주유완료일시 · 유류=계기 판매만
일평균 대비 금일 출고 현황 노즐회전량 파일(금일 현재까지)을 넣을 때마다 갱신 · 게이지보드 일평균/노즐 설정은 변경하지 않음

빠른 연속입력

숫자 입력 → Enter → 다음 탱크로 자동 이동

Enter=다음 · Shift+Enter=이전 · 빈칸 Enter=건너뜀(값 유지) · T12에서 Enter=발주계산으로 이동
데드스톡(Dead Stock·최저재고선) 5드럼 자동 차감 · 무연 140드럼차(20×7칸) · 경유 155드럼차(35+20×6칸) / 160드럼차(20×8칸) · 이관탱크: 직접 하화가 불가한 부족분을 받아 두었다가 해당 탱크로 이관 · 입력값은 이 브라우저에 자동 저장
